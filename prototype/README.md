# TACNET-7 界面原型（v0.1）

SILENT DEEP 的 UI / UX 交互探索原型。**不包含真实玩法**，数值和剧情都是摆样子的，只用来试界面、操作手感和音效。

## 运行

纯静态页面，没有构建步骤。直接用浏览器打开 `index.html` 即可；如果浏览器限制本地文件，在 `prototype/` 目录下起一个静态服务：

```
python3 -m http.server 8000
# 打开 http://localhost:8000/        （完整开机流程）
# 打开 http://localhost:8000/?skip   （跳过开机，直接进主界面）
```

字体从 CDN 加载（VT323、Fusion Pixel 12px），离线时回退到系统等宽字体。音效全部用 WebAudio 实时合成，没有音频文件。建议戴耳机。

## 做了什么

| 模块 | 键 | 能试的交互 |
|---|---|---|
| `BOOT` | — | 逐行自检（FAIL / DEGRADED），冷启动时在 38MW 预算内选择先启动的系统 |
| `TACPLOT` | F1 | 距离圈 + 右侧数据栏（参考 01、02）。点方位线选目标，`M` 记录方位线，转向后再记一次得到交叉估算；`P` 主动 Ping 得到精确位置但暴露自己 |
| `SONAR` | F2 | 频谱瀑布，线谱与声纹库比对，缺失的谐波标红。`R` 存一份读数 |
| `CONTACT LOG` | F3 | 目标表，点击 CLASS 手动改分类，开火许可跟着分类走 |
| `ELEC` | F4 | 反应堆功率、母线、断路器，每一项都显示噪声代价 |
| `WEAPONS` | F5 | 四具发射管 + 弹药舱。每具管可装不同型号（线导 / 被动自导 / 超空泡 / 诱饵 / 水雷），走完 装填 → 注水 → 开管门 → 发射，每一步都有噪声尖峰。发射组合（齐射）可编辑：选哪几具管、发射间隔、方位散布。数字键 `1~4` 准备对应发射管，`Enter` 发射当前组合 |
| `HULL` | F6 | 舰体侧面分布图：7 个舱段和舱内装备，状态直接读取其他界面的数据（断路器、发射管、反应堆）。点舱段看详情；可模拟进水、关水密门、派损管队。超过安全深度 450m 后艇壳会出现应力线 |
| `DIFF` | F7 | 同一目标两份读数对比，变化值标红；数值分毫不差时报警 |
| `COMMS` | F8 | UQC 呼叫 + 摩尔斯码。回声体回应太快、节奏完全一致 |
| `CHART` | F9 | 网格海图（参考 03），未探索区域是噪点，惯导误差椭圆，`F` 地标校准 |
| `BESTIARY` | — | Bayer 抖动剪影（参考 05），观测次数越多越清晰。从按钮台或命令 `BESTIARY` 打开 |
| `APPROACH` | — | 渡鸦环礁进港程序图（字符画）。从 CHART 或按钮台打开 |
| `REPORT` | — | 取景框 + 暗红字符噪点弹窗（参考 04） |

通用交互：

- 三台终端（CON-1 ~ CON-3），`TAB` 切换焦点终端，F 键把界面开在焦点终端上。已在别的终端打开的界面会直接跳过去
- CON-1 上有一直残留的烧屏画面
- 命令行：按任意字母或 `` ` `` 聚焦。`HELP` 列出全部命令，例如 `FIRE T2 BRG 118 RUN 4000`
- `S` 静默航行：全屏变暗、按键声变弱，打字声会计入噪声值
- `H` 戴耳机：接触目标的声音按相对方位左右摆放
- 内部广播：底部带失真的短句，`VOICE ON` 开启浏览器语音朗读
- 按钮台：终端下方一排实体按键，每个键就是一条命令（和在命令行里输入完全一样），指示灯显示当前状态。`PING`、`SALVO`、`DECOY` 这类危险操作带保护盖，3 秒内要按两下。命令行里输入一条命令后按 `+ 存为按键` 可以存成自定义按键（存在本机浏览器里），右键删除。`Q` 显示 / 隐藏按钮台
- 滚动条按终端的磷光色绘制（虚线轨道 + 方块滑块）。Firefox 只支持颜色，不支持形状

## 演示用的命令

| 命令 | 效果 |
|---|---|
| `CONTACT` | 出现新接触目标 S-09（进主界面 45 秒后也会自动出现） |
| `LEVIATHAN` | 所有声音慢慢消失，声呐上所有信号消失，约 26 秒后结束 |
| `DAMAGE 2` / `REPAIR 2` | 2 号终端花屏、乱码、刷新变慢 / 修复并消磁 |
| `BREAKER CON3 OFF` | 3 号终端断电，显示 NO SIGNAL |
| `DEGAUSS` | 消磁抖动 + "咚"声 |
| `ARCHIVE` | 战前存档画面：唯一出现高饱和彩色的地方 |
| `PHOSPHOR` | 在"每台设备一种磷光色"和"全部单色绿"之间切换，用来对比视觉方向 |
| `CONSOLES 2` | 只剩两台终端 |
| `LOAD T3 VA-111` / `PREP ALL` / `SALVO A` | 装填、准备全部发射管、发射组合 A |
| `LEAK 2` / `SEAL 2` / `DC 2` | 2 号舱进水 / 关水密门 / 派损管队 |
| `TIME 60` | 调整时间压缩倍率（默认 ×20） |

## 一次识别遭遇怎么走

1. `CONTACT` → 广播"新接触目标"，S-09 只有一条方位线
2. TACPLOT 按 `M` 记录方位线 → 点 TURN +35 转向，等一会儿再按 `M` → 两线交叉，给出距离估算
3. SONAR 看线谱比对：有一根谐波对不上
4. 按两次 `R` 存读数 → DIFF 里转速在变，是真的机械
5. S-07 走同样流程：线谱比对缺谐波，DIFF 里数值分毫不差，COMMS 回应间隔 0.35 秒
6. 决定：CONTACT LOG 改分类 → ELEC 合上 TUBE → WEAPONS 里 PREP（注水、开管门，对方能听到）→ `FIRE T1` 或 `SALVO A`；或者 `S` 静默。对回声体用被动自导鱼雷打不中：它没有机械噪声

## 文件

```
index.html
css/crt.css          CRT 外观：扫描线、辉光、暗角、刷新横线、消磁、损坏抖动
js/core.js           全局状态、工具函数、模块注册、事件总线
js/audio.js          WebAudio 合成：环境层 / 设备层 / 信息层
js/mod-tacplot.js    TACPLOT + 方位线交叉 + Ping
js/mod-sonar.js      SONAR 瀑布 + DIFF
js/mod-panels.js     CONTACT LOG / ELEC / COMMS
js/mod-chart.js      CHART + APPROACH
js/mod-bestiary.js   BESTIARY
js/mod-weapons.js    WEAPONS：鱼雷型号、发射管状态机、齐射组合、鱼雷航行与结算
js/mod-hull.js       HULL：舱段、装备分布、进水与损管
js/quick.js          按钮台
js/app.js            BOOT、控制台管理、命令行、广播、REPORT、演示剧情、主循环
```

新加一个界面：在 `js/` 里调用 `SD.register({ code, cn, ph, fkey, create(root) { ...; return { tick, key } } })`，再在 `index.html` 里引入。不管界面开没开都要推进的状态（装填进度、进水、鱼雷航行）用 `SD.addSystem(fn)` 挂到主循环上。

## 原型里的简化 / 待定

- CRT 效果用 CSS 叠加层实现，没有做屏幕曲面变形；文档里提的 WebGL 着色器留到后面
- 视觉方向没定，所以做了 `PHOSPHOR` 切换，不代表已经选了分色方案
- 方位线交叉用的是理想几何，没有真实的目标运动分析误差模型
- 鱼雷命中只按方位误差和制导方式粗略判断，不模拟真实弹道
- 舰体舱段划分、装备位置和鱼雷型号都是设计提案，没有参考图支撑
- 只在桌面 Chrome / Safari 宽屏下调过布局
