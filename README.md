# SILENT DEEP

核战争之后的末世海洋。玩家是一艘核动力潜艇的指挥官：没有卫星，只能靠声呐感知世界；外面全是污染，人只能待在艇里。玩家要猎杀变异巨兽，还要分辨遇到的人类舰艇是敌是友，让潜艇尽可能活下去。

整个游戏都在复古 CRT 终端上进行。玩法来自玩家在界面上的决策，沉浸感靠界面和音效来提供。
