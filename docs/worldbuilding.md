# SILENT DEEP 世界观设定（草案 v0.1）

> 备选中文名：《回声纪元》《深渊静默》《黑水》

## 一、核心设定：为什么只剩潜艇

**灰烬之夏（旧历 2041 年）**
一场持续七天的全面核交换。最致命的是战争初期的高空核爆 EMP，它摧毁了几乎所有民用电子设备。数百次反卫星打击又引发凯斯勒效应：轨道碎片连锁撞击，把近地轨道变成一片碎片带。卫星从此不可能再发射，GPS 和卫星通讯永久消失。

**地表的死亡**
核冬天叠加臭氧层崩溃，地表变成"灰雪带"，紫外线和放射性尘埃让人无法在户外存活。陆地上的幸存者只能躲在地下掩体里，然后一个接一个失联。

**潜艇为什么活了下来**
- 战争爆发时处在深海，海水挡住了 EMP 和第一波辐射
- 军用系统本来就做过抗电磁加固，用的是老式、冗余的电子设备
- 核反应堆能提供几十年的电力、淡水和氧气

**现在是静默纪元 37 年。** 艇上的老一代船员正在老去，新一代是在艇里出生的"艇生代"，他们一辈子没见过太阳。

## 二、为什么界面是 TUI（写进剧情的理由）

- 现代的触屏和图形系统在战争中全部烧毁，只有老式的抗辐射终端还在工作
- 艇上的操作系统叫 `TACNET-7`，是冷战时期的遗产，后来被船员用备件反复修补过
- 屏幕上的花屏、乱码、掉帧是设备老化的表现，可以直接做成玩法：受损时终端会显示错误信息
- 艇上没有现成的海图，地图靠玩家一点一点探测、手动标注出来

## 三、核心矛盾：反应堆是你的命，也会把怪兽引过来

- 反应堆功率越高，航速、武器、生命维持就越好，但噪声和热量也越大
- 变异生物对反应堆的低频泵噪声和辐射特别敏感，会循着声音找过来
- 玩家要一直在两者之间取舍：全速逃跑，还是关掉一切、在黑暗里屏住呼吸

| 手段 | 效果 | 代价 |
|---|---|---|
| 被动声呐 | 安全地监听 | 信息模糊，只能估算距离 |
| 主动声呐 Ping | 定位精确 | 等于向整片海域宣告"我在这里" |
| 躲在温跃层下 | 声波被折射，很难被发现 | 自己也听不清上面的动静 |
| 惯性导航 | 唯一的定位手段 | 误差会越积越大，要靠地标重新校准 |

## 四、敌我识别：最难的不是打，是认清对方是谁

没有 IFF 敌我识别系统之后，玩家只能靠这些线索判断：

1. **声纹**：螺旋桨叶片数、转速、泵噪声。但声纹库残缺不全，需要在游戏中慢慢补全
2. **行为**：对方是在接近、跟踪、绕到你侧后，还是保持距离
3. **水声通讯**：用水下电话（UQC）或敲击艇壳发摩尔斯码。可以问对方旧日呼号和暗号
4. **欺骗**：海盗会播放录下来的友军声纹，有些怪兽甚至会模仿人类的声音

> 航海日志 37.089：S-07 用标准摩尔斯回应了呼叫，暗号正确。
> 但它回应的速度太快了，而且每一遍敲击的节奏都完全一样。
> 我下令保持静默。三小时后，它离开了。没有螺旋桨声。

## 五、人类势力

| 势力 | 描述 | 态度 |
|---|---|---|
| 舰队协约 | 残存海军的联盟，还在坚持旧日的交战规则和军衔。纪律严明，但越来越偏执，会"征用"其他潜艇 | 有条件友好 |
| 锈帮 | 开改装柴电潜艇的拾荒者和海盗，擅长伪造信号、布设诱饵 | 敌对为主，可以交易 |
| 静默教团 | 把巨兽当作"新神"来崇拜，会用声波把巨兽引向别人 | 危险，但掌握很多关于巨兽的知识 |
| 孤岛聚落 | 残存在钻井平台、环礁、海底研究站里的人群，是补给和剧情的主要来源 | 中立，要建立信任 |
| 死手协议 | 战时部署的自动猎杀潜航器，仍在执行三十多年前的命令，把所有核动力信号都当作目标 | 绝对敌对，没有人操控 |
| 另一位指挥官 | 和玩家处境相同的独行潜艇 | 由玩家的选择决定 |

## 六、变异生物：它们不全是怪物

- **Ⅰ级 · 漂流群**：变异水母群，会堵塞进水口，导致冷却故障
- **Ⅱ级 · 铁颚蟹**：吸附在艇壳上啃食，要浮上浅水或者放电才能清除
- **Ⅲ级 · 深渊眼**：巨型头足类，会缠住潜艇往深处拖，考验下潜极限
- **Ⅲ级 · 回声体**：会模仿声纹和人类通讯的掠食者，是游戏里的恐怖担当
- **Ⅳ级 · 哀歌鲸**：体型巨大但通常不具攻击性。跟着它们的歌声往往能找到洋流和资源。杀掉它会得到大量物资，但也会招来后果
- **Ⅴ级 · 利维坦**：区域性的传说级存在，出现的时候，声呐屏幕上的所有信号都会消失

道德选择：有些"怪兽"只是在保护自己的领地。打不打、怎么打，会影响后面的生态和结局。

## 七、生存资源

- **燃料棒**：反应堆的剩余寿命，是整个游戏的终极倒计时
- **氧气 / 淡水**：靠电解和蒸馏获得，依赖电力
- **食物**：艇内的藻类农场，加上靠港时换来的补给
- **弹药**：鱼雷非常稀缺，每一发都要算计
- **艇壳完整度 / 最大安全深度**
- **船员状态**：辐射剂量、幽闭症、士气、派系矛盾。老船员和艇生代之间会产生冲突

## 八、主线谜团

1. **灯塔信号**：一段从未知坐标重复发出的神秘广播，传说它来自一块"绿洲"，那里的地表还能住人
2. **变异为什么这么快？** 单靠辐射解释不了三十年里的巨变。深海海沟里也许有战前的秘密项目，或者有什么东西被核爆唤醒了
3. **死手协议的指挥中枢**还在某个地方运行，关掉它或者夺取它
4. **可能的结局**：找到绿洲 / 加入教团与巨兽共生 / 成为新的舰队霸主 / 反应堆熄灭，永远沉在黑暗里

## 九、核心玩法循环

```
巡航 → 监听 → 识别接触目标 → 决策（攻击 / 规避 / 通讯 / 跟随）
  ↑                                              ↓
靠港补给 / 交易 ← 船员事件 / 故障维修 ← 结果与代价
```
