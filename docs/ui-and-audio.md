# SILENT DEEP 界面与音效设计（草案 v0.1）

游戏的交互全部发生在复古 CRT 终端上。玩法来自玩家在界面上做的决策，沉浸感靠界面和音效来提供。

## 二、视觉方向（待定）

参考图分成两派：一半是单色磷光（01、02、04、06），一半是高饱和的彩色（07、08）。

建议的方案：
- 每台设备固定一种磷光颜色。比如声呐和雷达用绿色，系统和通讯用琥珀色
- 红色只在报警时出现
- 彩色风格只留给特殊场景，比如打开一份战前的存档画面，让它和末世的单色界面形成反差

CRT 效果：扫描线、辉光、屏幕曲面、边角暗角、刷新横线、余晖拖影、消磁时的色彩抖动。

## 三、界面模块

以下是设计提案。标了参考图编号的，是有图可以对照的；没标的，是从玩法需要推出来的。

1. **`BOOT` 开机自检**：每次开局或断电重启，屏幕都会一行一行滚出自检日志。设备受损时，这一行会显示 `FAIL` 或 `DEGRADED`。电力不够的时候，玩家要决定先启动哪些系统
2. **`TACPLOT` 战术态势图**（参考 01、02）：以本艇为中心，按方位和距离显示接触目标，右侧是数据栏。被动声呐只能给出方位线，给不出距离。玩家要变换航向，从多个位置测方位，交叉定位才能算出距离（目标运动分析）。用主动声呐 Ping 能马上得到精确位置，代价是暴露自己
3. **`SONAR` 频谱瀑布**：横轴是频率，纵轴是时间，每个声源都会留下一组有特征的频率线谱。玩家拿线谱和声纹库比对。回声体能模仿人类潜艇的线谱，但会少一根电源谐波，这就是识破它的线索
4. **`CONTACT LOG` 接触目标日志**：一张表列出所有接触目标。玩家可以手动修改目标分类，系统会按玩家标的分类决定是否允许开火。标错了，后果由玩家承担
5. **`ELEC` 电力与反应堆原理图**：反应堆、发电机、母线、各子系统。玩家拉断路器、分配功率。功率越高噪声越大，这张图就是核心矛盾的操作界面
6. **`CHART` 海图**（参考 03）：战略层地图。没去过的区域是空白，靠声呐探测一块块填上。标注势力范围、洋流和巨兽领地。惯性导航误差显示成一片越来越大的"可能位置"区域，经过已知地标时才会收缩
7. **`APPROACH` 进港程序图**：每个孤岛聚落都有一张进港图，标出水道、安全深度和转向点。进港图本身就是可以交易的物资
8. **`DIFF` 异常对比**：同一个目标的两次读数放在一起，变化的数值被标红。例如 S-07 的线谱三分钟里分毫不差，真正的机械不可能这么稳定。这是恐怖感的主要来源
9. **`BESTIARY` 怪兽图鉴**（参考 05）：用抖动点阵图表现，图像随着观测次数增加逐渐清晰
10. **`REPORT` 事件与结算**（参考 04）：带取景框的弹窗
11. **`WEAPONS` 武器系统**：发射管装填不同型号的鱼雷和诱饵，发射前要注水、开管门，每一步都有噪声，开管门对方听得见。可以预先编好发射组合（哪几具管、间隔、散布）。开火许可仍然跟着 `CONTACT LOG` 里玩家标的分类走
12. **`HULL` 舰体侧面分布图**：按舱段显示装备系统和状态，是其他界面数据的另一个视角。进水、水密门、损管队在这里操作；超过安全深度时艇壳出现应力线
13. **快捷按钮台**：终端下方的实体按键，每个键对应一条命令。危险操作（主动声呐、齐射）带保护盖，要按两次

11~13 是原型里新增的设计提案，没有参考图支撑。

## 四、交互规则

1. **控制台数量有限**：艇上只有 2 到 3 台能用的终端，同一时间只能看其中几个界面。玩家的注意力本身就是一种资源
2. **命令行加快捷键**：常用操作用 F1 到 F8 快速切换界面，复杂操作输入命令，比如 `FIRE T2 BRG 118 RUN 4000`
3. **设备损坏直接体现在界面上**：字符乱码、整行丢失、刷新变慢、屏幕花屏
4. **静默航行时**：屏幕亮度调低，按键声变弱，界面本身也在"屏住呼吸"
5. **烧屏**：某台终端上一直残留一幅战争当天的画面，淡淡地印在屏幕上

## 五、音效：让声音本身成为信息

| 层 | 内容 | 作用 |
|---|---|---|
| 环境层 | 反应堆嗡鸣、通风声、艇壳在水压下吱嘎作响、管道滴水 | 营造幽闭感。下潜越深，艇壳的声音越响 |
| 设备层 | CRT 高频啸叫、消磁的"咚"声、继电器咔哒声、机械键盘、打印机 | 让界面操作有实在的手感 |
| 信息层 | 玩家戴上耳机就能直接收听接触目标：螺旋桨空化声、鲸歌、甲壳类的咔嗒声 | 声音的左右声道对应目标方位，熟练的玩家光靠听就能分辨 |

- 利维坦出现之前，所有声音都会慢慢消失，连海洋生物的背景噪声都没了。寂静本身就是警报
- 静默航行时，玩家打字、开关舱门的声音也会计入本艇的噪声值
- 船员的汇报通过内部广播传来，是带失真的短句，例如"声呐报告，方位一一八，新接触目标"

## 六、一次遭遇在各个界面上怎么流转

```
[SONAR]    瀑布图上出现一组新线谱 → 系统标记 S-09
[TACPLOT]  只有一条方位线 → 玩家转向 30°，重新测方位
[TACPLOT]  两条方位线交叉 → 估算距离 5.1km
[SONAR]    线谱比对 → 锈帮改装艇 72%，但有一根谐波对不上
[DIFF]     对比两次读数 → 螺旋桨转速在变 → 是真的机械
[COMMS]    用摩尔斯码呼叫 → 对方回应，要求交易
[ELEC]     把功率调给鱼雷管预热，以防万一（噪声 +12dB）
[决策]     交易 / 开火 / 静默撤离
```

## 七、实现备忘

- 中文要用点阵字体：Fusion Pixel、Zpix 或文泉驿点阵。英文可以用 VT323 或 IBM 3270 风格的字体
- CRT 效果用 WebGL 着色器实现，网页、Godot 和 Unity 都能做到
